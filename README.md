## 一、项目简介

本项目报名参加 **「百年京张 AI 创新带城市设计开源征集」**（主办方：北京市发改委、市规自委、海淀区政府；官方仓库 `open-city-ai/haidian`，官网 haidian.open-city.ai）。

方案聚焦 **京张铁路遗址公园沿线约 43.6 km²** 的真实城区，提出一套由 AI 驱动、可开源协作、可真实落地的创新带城市设计方案。

与"单一大模型一次性生成方案"不同，本方案由 **落朵机器人大脑（SkyDuo 总控）** 统筹 **23 席专业 AI Agent** 构成完整作战矩阵——从赛事资料研读、产业定位、空间规划、历史文脉保护、人群行为研判，到合规自检与评审，全链路多智能体分工协作，真实演练了 AI 军团在复杂城市规划场景中的实战能力。

- **参赛节点**：2026-08-07 开放征集 · 2026-08-31 截止
- **入选激励**：优秀方案 GitHub 昵称刻碑永久保留

## 二、核心主张与方案概念

### 2.1 一句话主张

> AI 创新带的核心不在"建筑有多新"，而在"遗迹之上长出新的精神"——京张铁路的遗产不是包袱，是 IP。

### 2.2 差异化主线：City-as-Repo（城市即开源仓库）

我们将百年京张沿线城区视为一座"开源城市仓库"：

- **落朵·智轨城（Luoduo Agent-City）** 为方案命名体系，「智轨」双关京张铁路之轨与智能体调度之轨；
- 每一次 Agent 协同讨论、空间推演、指标复算、自检迭代，均留有可追溯的 GitHub 提交记录；
- 落朵已运行的真实生态（9 大业务系统）作为"可运行的组件"映射到城区场景，使方案不止于纸面，而具备真实落地接口——这是本方案相对纯概念方案的护城河。

### 2.3 空间框架：三区两翼

- **三核心区**：众智原 · 原点社区 · 大钟智核
- **两翼**：中关村赋能翼 · 小月河场景翼

> 合规基线：所有空间方案均按赛事规范标注为 **「概念建议 / 参考方案」**，不替代正式规划、不构成政府审定结论。

## 四、方案亮点

### 4.1 四大差异化亮点

| # | 亮点 | 说明 |
|---|------|------|
| 1 | **AI 原生规划闭环** | 24 席 Agent 矩阵全链路协同作业，非单一大模型一次性生成 |
| 2 | **历史 + 科技双 IP** | 詹天佑精神与 AI 原生城市的融合，保留京张铁路历史遗存作为公园叙事主脉 |
| 3 | **算力基础设施预留** | 在道路/市政规划中预埋 AI 创新带所需的数字基础设施、算力管道 |
| 4 | **全流程开源留痕** | 每一步 Agent 讨论、迭代、自检均有 GitHub 记录，可追溯、可复现 |

### 4.2 真实生态落地（差异化护城河）

以下均为落朵 **已运行系统**，可作为「已落地能力」证据映射到创新带场景，区别于纯概念方案：

- 挺盈宝无人商店（tyb）→ AI+ 无人零售生活圈
- 易得/落朵自动售货机（yd）→ AI+ 即时服务微节点
- 康养机器人 → AI+ 康养陪伴社区
- EMQX 数据采集（cj）→ AI+ 城市运行感知底座
- 流媒体/大屏（sy/sj）→ AI+ 公共信息传播节点
- 论坛/社区（forum_hub）→ AI+ 开发者共创社区
- 落朵机器人大脑（jt）→ 城市级 Agent 编排中枢
- 登登 WiFi → AI+ 公共连接基础设施

## 五、提交材料清单

本方案严格遵循官方 `professional_design_package` 提交契约（`package_state = ready_for_review`，`self_check` 全 PASS）。核心产物：

**规划文本与契约文件**
- `proposal.md` — 中英双语规划文本（含证据标记 `[source:]` / `[standard:]` / `[data:]` / `[metric:]`）
- `manifest.json` — 提交包清单（含 SHA-256）
- `agent.json` — AI 参与与生成披露
- `compliance_matrix.json` / `standard_matrix.json` / `design_depth_matrix.json` — 合规与设计深度自检矩阵
- `metrics.json` — 指标族（从几何复算得出）
- `sources.json` / `assumptions.json` / `self_check.json` / `risk.json` — 来源、假设、自检、风险披露

**空间与几何**
- `geometry/*.geojson` — 站点边界、重点区、用地分区、建筑、道路、蓝绿、公共空间、分期、约束（EPSG:4326，面积经 EPSG:4548 复算）

**图件与可视化**
- 5 张必填图：`site-overview` / `land-use-structure` / `key-areas` / `mobility-bluegreen` / `metrics-evidence`
- `report/proposal.html` — 离线报告
- `drawings/*.pdf` — A3 图册 / A0 展板
- `visual/index.html` — 离线静态可视化
