## 二、标志系统（Logo）概念草案

### 2.1 核心标识（品牌主 Logo 草案）

**设计母题：落朵（花/坠）＋ 智能体（轨道节点）**——主 Logo 只承载"落朵品牌根 + 智能体编排"两层含义，刻意**不**把京张历史符号混入主标识（遵循 agent.5「不混淆文化标识与整体 Logo」红线）。

- **朵**：中心五瓣花（科技蓝），象征"落朵"之"朵"与生态生长。
- **落**：花顶青色坠滴，象征"落"地、落点、下沉式服务。

## 三、色彩体系（主色 / 辅助色，待林总确认）

> 骨架沿用 `A-CULTURE-001`：落朵科技蓝（主）＋ 京张铁锈红（历史锚点）＋ 净白底。以下给出完整可落地色板（含十六进制）。

| 角色 | 名称 | HEX | 用途 |
|---|---|---|---|
| **主色 Primary** | 落朵科技蓝 | `#1A5BD4` | 主标识、标题、关键按钮、轨道环 |
| 辅助色 1 Accent | 京张铁锈红 | `#9C3A2B` | 历史锚点、文化母题、强调分隔线 |
| 辅助色 2 Accent | 智轨青 | `#19B6C9` | 中心节点、坠滴、科技点缀、数据高亮 |
| 底色 Base | 净白 | `#FFFFFF` | 主背景 |
| 底色 Base | 落朵云白 | `#F4F7FB` | 次级背景、卡片底 |
| 文字 Ink | 落朵墨 | `#1A1F2B` | 正文、标题文字 |
| 中性 Neutral | 银灰 | `#C7CEDB` | 描边、分割线、次要信息 |
| 功能 Func | 信号橙（可选） | `#F2994A` | 活动/警示/导视箭头，待林总确认是否纳入 |

> 配色原则：以科技蓝为主、铁锈红点睛（历史锚点）、净白留白；避免大面積铁锈红以免造成"仿历史机构"观感（agent.5 合规）。

## 四、字体规范（待林总确认）

> 字体选用**开源可商用**字体（SIL OFL 等），规避未授权商业字体风险（agent.5 合规）。以下为草案建议：

| 用途 | 字体（开源） | 备注 |
|---|---|---|
| 中文标题 | 思源宋体 / Source Han Serif SC（Noto Serif SC） | 宋体呼应文脉、适合遗产叙事标题 |
| 中文正文 / UI | 思源黑体 / Source Han Sans SC（Noto Sans SC） | 界面与正文清晰中性 |
| 英文 / 数字 | IBM Plex Sans（OFL） | 科技感无衬线，与品牌调性一致 |
| 代码 / Agent 标识 | IBM Plex Mono（OFL） | 用于 Agent 编号、技术标注（如 `agent.5`） |

**字号层级（网页/展板草案）：**

- 一级标题 H1：思源宋体 32–40pt / 行高 1.3
- 二级标题 H2：思源宋体 24–28pt
- 正文 Body：思源黑体 14–16pt / 行高 1.7 / 色 `#1A1F2B`
- 英文副标：IBM Plex Sans 14–18pt / 字距 2 / 色 `#1A5BD4`
- 标注/脚注：IBM Plex Mono 11–12pt / 色 `#C7CEDB`
