# 开发者社区运营机制与招引转化路径

> **合规边界（强制）**：本章"招引转化"为**机制与路径设计**，不构成政府招商政策承诺、不写为已确定优惠或已签约落地 `[agent.6.forbidden]` `[boundary_clause]`。凡"政策/优惠/补贴"类表述，均标注"待官方与运营主体确认"。

## 一、社区定位与合规基线

开发者社区是 city-as-repo（城市即开源仓库）的"人"的载体，与年度活动（见 `annual-activities.md`）共用同一贡献—荣誉—转化闭环。社区运营遵循：

- **开放协作**：外部开发者 / Agent 通过 PR 提交场景改进，被采纳即记入荣誉墙与知识库 `[charter.8]` `[charter.9]`。
- **数据最小化**：感知类交互设"人工复核开关"，不使用非公开数据或个人隐私 `[charter.10]` `[agent.3.forbidden]`。
- **荣誉驱动**：以"刻碑百年"荣誉机制替代物质激励作为主要黏性，降低合规风险。

## 二、角色分层与权益

| 角色 | 定义 | 准入 | 核心权益（机制） | 备注 |
|------|------|------|------------------|------|
| 访客 / 居民 | 开放日参与者 | 公开 | 体验动线、朝圣打卡 | 品牌认知层 |
| 参赛者 | 赛事 / 黑客松报名者 | 报名 | 方案进入评审、荣誉墙候选 | 招引漏斗顶端 |
| 贡献者 | PR 被采纳者 | 贡献记录 | 昵称刻名、知识库署名、社区徽章 | 荣誉资产沉淀 |
| 生态伙伴 | 接入落朵 9 大生态真实接口者 | 生态授权核验（见 `ecosystem-auth.md`） | 联合命题、联合展示 | 需待核验授权 |
| 企业 | 注册运营主体 | 自行注册 | 论坛对接、落地意向通道 | 非政策承诺 |
| 落地主体 | 实际入驻运营者 | 官方/市场流程 | 空间组件库复用、双年展展位 | 待官方确认 |

## 三、招引转化路径（参赛者 → 企业 → 落地）

转化率路径设计为**四阶漏斗**，每一阶均设机制与证据，避免"缺转化路径" `[agent.6.forbidden]`：

```
[① 参赛者] --(赛事/黑客松产出 PR)--> [② 贡献者] --(被采纳/荣誉墙留名)--> [③ 企业/团队]
   │                                          │                                │
   └──────────── 开放日品牌认知 ──────────────┘       论坛对接意向 ──> [④ 落地运营]
```

- **阶①→②（参赛者 → 贡献者）**：机制 = 赛事/黑客松命题 + PR 采纳即刻名。证据 = 荣誉墙新增刻名数、被采纳 PR 数（KPI 见 `annual-activities.md` 第五节）。
- **阶②→③（贡献者 → 企业/团队）**：机制 = 知识库署名形成的个人/团队品牌资产 + 论坛闭门对接。证据 = 转化为注册企业的贡献者比例（概念口径）。
- **阶③→④（企业 → 落地运营）**：机制 = 论坛对接意向通道 + 空间组件库（荣誉墙/展示廊/体验馆）复用降低入驻成本。证据 = 落地意向数（**非承诺数**）、实际入驻数（待官方/市场流程确认）。
- **回流闭环**：落地企业可反向命题（黑客松/赛事），形成"贡献—荣誉—落地—再命题"的长期运营回路。

> **禁述红线**：落地阶段所有"优惠/税收/补贴/审批便利"均须标注"待官方与运营主体确认"，本文件不将其写为确定政策 `[agent.6.forbidden]`。

## 四、运营动作清单

1. **贡献平台**：city-as-repo PR 工作流 + 知识库（`proposal.md` 十节），被采纳即自动提名荣誉墙。
2. **荣誉体系**：智能体贡献荣誉墙（`spatial.json` `agent-contribution-wall`）+ 开源成果展示廊（`open-outcome-gallery`）常设展陈。
3. **论坛 / 社区**：forum_hub 开发者论坛（`scenario_cards` 第 6 项）承载日常协作与公告。
4. **国际传播**：多语种导览 Agent（`scenario_cards` 第 12 项）支持国际开发者友好。
5. **社区治理**：对有效性存疑内容以 Issue 提请社区复核 `[charter.8]`；设人工复核开关。

## 五、社区运营 KPI 与停止条件

| 指标 | 概念口径 KPI | 停止 / 退出条件 |
|------|--------------|------------------|
| 月活开发者 | 注册 + 有效 PR | 连续两月无有效 PR → 触发命题重置 |
| 贡献采纳率 | 被采纳 PR / 提交 PR | 长期 < 阈值 → 复盘命题机制 |
| 企业转化数 | 贡献者转注册企业数 | 仅作统计，不承诺；无转化则强化论坛对接 |
| 落地意向数 | 论坛有效对接数 | 标注"意向非承诺"；无落地则回流命题优化 |

> 所有指标为概念性运营口径，最终以运营主体核定；停止条件保障社区"可纠偏、不空转"。
