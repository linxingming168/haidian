## S-01 智能通勤接驳

- **场景名**：智能通勤接驳（人字形铁路接驳环）
- **目标用户**：每日往返三区（众智园 / 原点社区 / 大钟寺）的科研与企业通勤者、轨道接驳人群。
- **触发条件**：用户在小程序设定通勤 OD（起讫点）与时段；或轨道站点（既有 13 号线、昌平线节点）客流达到阈值；或园区预约会议临近。
- **Agent 动作**：落朵大脑 jt 聚合轨道到站时刻、慢行廊道状态、园区预约，生成"轨道+慢行+短驳"的接驳建议；挺盈宝 tyb 微仓按到站波次预置补给。全程仅用公开时刻表与用户授权位置，不涉及持续追踪。
- **空间载体**：京张遗址公园活力带两侧慢行接驳点、三区接驳驿站、轨道站点 P+R 衔接处（概念布点，非轨道线位结论）。
- **运营机制**：以 city-as-repo 的 PR 机制征集接驳优化；接驳排班与补给由运营方在"人工复核开关"下确认，Agent 仅出建议。
- **核心KPI**：接驳等待时长下降比例、三区间 10 分钟可达覆盖率、用户授权使用率（非覆盖率式监控）。

## S-02 遗址研学

- **场景名**：遗址研学（京张文脉沉浸课堂）
- **目标用户**：中小学生研学团体、高校专业调研、亲子家庭、文化志愿者。
- **触发条件**：团体在原点社区或遗址公园预约研学动线；或到达导览屏触发多语种讲解请求。
- **Agent 动作**：文旅AI导览 Agent 按"詹天佑人字形铁路—百年京张—AI 创新带"叙事线推送分层解说（历史 / 工程 / 创新三档），结合开源成果展示廊内容做延伸；论坛 forum_hub 沉淀研学笔记与教案，供社区复现。
- **空间载体**：京张遗址公园主轴、智能体贡献荣誉墙、开源成果展示廊、研学驿站（概念选址）。
- **运营机制**：研学内容由文化专员与社区审核后发布，Agent 不擅自生成未经核实的史实表述；叙事严格锚定公共文化遗产，不混淆文化标识与整体 Logo `[agent.5.forbidden]`。
- **核心KPI**：研学动线完成率、分层解说复用率、研学笔记在论坛 forum_hub 的复现次数。

## S-03 慢行缝合

- **场景名**：慢行缝合（东西缝合·南北贯通）
- **目标用户**：步行与骑行通勤者、慢跑与休闲人群、无障碍出行者。
- **触发条件**：慢行廊道拥堵或断点上报；无障碍用户发起连贯路径请求；年度"智能体接力跑"活动期。
- **Agent 动作**：落朵大脑 jt 编排"遗址公园两侧缝合、南北主轴贯通"的连续性路径推荐，识别断点并生成可上报的织补建议（供专业团队深化）`[agent.4]`；不输出道路线形、桥隧或市政管线结论 `[boundary_clause.forbidden]`。
- **空间载体**：慢行缝合与南北贯通廊道、蓝绿公共空间网络、东西两翼衔接处（概念）。
- **运营机制**：断点建议经人工复核后进入 city-as-repo 议题池；活动期由运营方设定临时引导策略。
- **核心KPI**：主轴连续慢行可达率、断点上报→复核闭环时长、无障碍路径请求满足率。

## S-04 蓝绿康养

- **场景名**：蓝绿康养（绿地里的健康官）
- **目标用户**：社区长者、慢病管理人群、运动后恢复人群、康养访客。
- **触发条件**：用户在蓝绿节点签到康养活动；康养机器人（扁鹊）识别到需陪伴/提醒事项；环境传感达到适宜活动阈值。
- **Agent 动作**：康养机器人（扁鹊）提供适老化陪伴、用药与复诊提醒、轻量健康问答；EMQX cj 仅采集 anonymized 环境量（温湿度、空气质量、人流密度）用于活动安全与承载力评估，不采集个人身份与健康明细 `[charter.10]`。
- **空间载体**：蓝绿公共空间网络、适老化活动场地、社区健康小屋（概念）。
- **运营机制**：健康提醒为辅助信息，最终判断由用户与专业机构作出；所有个人数据本地留存、用户可撤回授权。
- **核心KPI**：康养活动参与人次、适老化设施使用率、环境舒适度达标时长占比。

## S-05 无人零售

- **场景名**：无人零售生活圈（10 分钟补给网）
- **目标用户**：AI 原点社区居民、园区办公人群、夜间补给需求者。
- **触发条件**：社区微仓库存低于阈值；用户在小程序下单即时补给；公共空间人流高峰触发补货波次。
- **Agent 动作**：挺盈宝 tyb 调度无人商店与易得 yd 售货机，按 10 分钟生活圈做库存与补货编排；落朵大脑 jt 在高峰做运力协同。仅处理订单与库存数据，不涉及人脸身份绑定 `[agent.3.forbidden]`。
- **空间载体**：AI 原点社区微节点、园区接驳驿站、公共空间触达点（概念布点）。
- **运营机制**：补货与定价由运营方复核；通过 city-as-repo PR 征集点位优化，被采纳记入荣誉墙。
- **核心KPI**：10 分钟补给可达覆盖率、缺货率、夜间订单满足率。

## S-06 社区养老

- **场景名**：社区养老（原点社区适老化陪伴）
- **目标用户**：独居与空巢长者、家属照护者、社区养老驿站。
- **触发条件**：康养机器人（扁鹊）周期性陪伴打卡；家属在端侧设定关怀事项；驿站发起集体活动。
- **Agent 动作**：康养机器人（扁鹊）提供日间陪伴、安全提醒、活动邀约与家属同步（经用户授权）；异常事件仅生成"待人工确认"工单，由驿站与家属处置，Agent 不直接决策紧急干预。
- **空间载体**：AI 原点社区适老化公共空间、社区养老驿站、健康小屋（概念）。
- **运营机制**：数据最小化、端侧优先；关怀信息经授权在家属与驿站间流转，设一键撤回；运营由社区与专业机构负责。
- **核心KPI**：长者陪伴触达率、家属授权同步覆盖率、异常工单人工处置及时率。

## S-07 创客孵化

- **场景名**：创客孵化（开源协作加速器）
- **目标用户**：AI 创业者、高校创客、驻园研究团队、投资人。
- **触发条件**：创业者在论坛 forum_hub 发起共创议题；驻园团队提交场景 PR；定期黑客松与路演排期。
- **Agent 动作**：落朵大脑 jt 将孵化任务拆解为可编排、可复盘、可审计的 Agent 任务；论坛 forum_hub 沉淀开源协作与可复现成果；为创业者提供资源地图与里程碑提醒（不承诺招商或投资结果）`[agent.2.forbidden]` `[agent.6.forbidden]`。
- **空间载体**：众智园 AI 自主创新加速区开放研发街区、落朵·智轨调度中枢体验馆、共享工坊（概念）。
- **运营机制**：孵化进度由创业团队自维护，Agent 仅做提醒与编排；资本对接表述为"可供专业团队/政府深化研究的建议"。
- **核心KPI**：论坛 forum_hub 共创议题数、可复现场景 PR 被采纳数、驻园团队里程碑达成率。

## S-08 文旅AI导览

- **场景名**：文旅AI导览（多语种无界导视）
- **目标用户**：国内外游客、国际访客、研学团体、无障碍出行者。
- **触发条件**：游客到达导览屏或扫码触发讲解；多语种切换请求；无障碍导览请求。
- **Agent 动作**：多语种 Agent 导视推送中/英/等多语言讲解与动线；流媒体大屏 sy/sj 发布公共信息与活动指南；内容由运营方审核，不生成未核实史实 `[agent.5.forbidden]`。
- **空间载体**：京张遗址公园主轴、三处朝圣地标（荣誉墙 / 成果廊 / 调度中枢）、公共导览屏（概念布点）。
- **运营机制**：发布内容经人工复核；国际访客数据仅用于语种偏好统计，不留存个人轨迹。
- **核心KPI**：多语种讲解调用率、导览屏信息更新及时率、无障碍导览请求满足率。

## S-09 应急安全

- **场景名**：应急安全（城市感知底座守护）
- **目标用户**：全域公众、物业与运营方、社区网格。
- **触发条件**：EMQX cj 感知到底层环境/设施异常（如积水、异常聚集、设施离线）；用户一键上报。
- **Agent 动作**：EMQX cj 作为"城市运行感知底座"真实运行能力，汇聚 anonymized 环境与安全事件；落朵大脑 jt 生成"待人工确认"态势与处置建议，推送运营方与网格，不自动执行强制措施。
- **空间载体**：全域感知节点、公共空间、接驳驿站（概念布点，复用既有设施）。
- **运营机制**：所有预警必须经人工复核与处置授权；感知数据最小化、 anonymized，设人工复核开关 `[charter.10]`。
- **核心KPI**：异常事件人工复核及时率、误报率、预警→处置闭环时长。

## S-10 低碳治理

- **场景名**：低碳治理（蓝绿与能耗协同）
- **目标用户**：园区运营方、社区、碳管理研究者。
- **触发条件**：公共空间人流与能耗数据达到评估阈值；蓝绿网络植被/灌溉需协同；登登 WiFi 提供普惠连接支撑数据回传。
- **Agent 动作**：EMQX cj 采集 anonymized 用能与人流，落朵大脑 jt 生成蓝绿养护与能耗协同建议（如错峰照明、灌溉排期），供运营方决策；不接入私人能耗或个体行为。
- **空间载体**：蓝绿公共空间网络、公共照明与灌溉节点、运营中心（概念）。
- **运营机制**：建议经人工复核后由运营方执行；碳数据仅作趋势参考，不替代官方核算。
- **核心KPI**：公共空间单位能耗趋势、蓝绿养护协同执行率、连接覆盖率（登登 WiFi）。

## S-11 智慧停车

- **场景名**：智慧停车（接驳节点泊位编排）
- **目标用户**：自驾通勤者、访客、接驳班车运营方。
- **触发条件**：轨道接驳节点泊位紧张；园区活动期停车需求上升；用户授权查询空位。
- **Agent 动作**：落朵大脑 jt 聚合授权泊位状态，生成"就近泊车+接驳"建议，引导至 P+R 与共享泊位；仅用授权状态数据，不做车牌持续追踪 `[charter.10]`。
- **空间载体**：三区接驳驿站、P+R 衔接处、公共停车场入口（概念布点）。
- **运营机制**：泊位策略由运营方设定与复核；通过 city-as-repo PR 征集点位优化。
- **核心KPI**：接驳节点泊位周转效率、自驾→轨道接驳转化率、空位查询命中率。

## S-12 邻里社交

- **场景名**：邻里社交（开源成果展示廊聚场）
- **目标用户**：社区居民、创客、游客、文化志愿者。
- **触发条件**：社区发起公共活动；开源成果展示廊更新展览；登登 WiFi 覆盖区内用户加入邻里话题。
- **Agent 动作**：登登 WiFi 提供普惠连接，论坛 forum_hub 承载邻里话题与活动召集；落朵大脑 jt 推荐适配的公共空间与时段，不推送未授权个性化内容。
- **空间载体**：AI 原点社区公共空间、开源成果展示廊、社区客厅（概念）。
- **运营机制**：话题与活动由社区自治，Agent 仅做聚合与提醒；内容设社区审核。
- **核心KPI**：社区活动场次、邻里话题活跃度、公共空间使用时段均衡度。

## 隐私与人工复核边界（全程适用）

- 所有感知类场景（S-04 / S-09 / S-10）均设**人工复核开关**，异常仅生成"待人工确认"工单，Agent 不自动执行强制动作 `[charter.10]`。
- 遵循**数据最小化**：采集 anonymized 环境/状态量，不使用人脸身份绑定、非公开数据或个人隐私 `[agent.3.forbidden]`。
- 不将概念设想表述为已批准运营；验证场景见 `validation-scenarios.md`，落地映射见 `scenario-space-operation-matrix.md` `[agent.3.forbidden]`。
