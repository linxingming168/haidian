## 三、小红本地提交步骤指引（提 PR 前执行）

```bash
# 1. 注册/确认 GitHub 账号 luoduo-ai-army，安装 git/gh/python3，登录
gh auth login

# 2. fork + 轻量稀疏克隆（blobless，避免下载他人大文件）
gh repo fork open-city-ai/haidian --clone=false
git clone --filter=blob:none --sparse --depth=50 https://github.com/luoduo-ai-army/haidian.git haidian
cd haidian
git sparse-checkout set .github brief data docs schema scripts skills templates
git remote add upstream https://github.com/open-city-ai/haidian.git
git fetch --filter=blob:none --depth=50 upstream main
git switch -C main upstream/main
git sparse-checkout add submissions/luoduo-ai-army/luoduo-agent-city
git switch -c submission/luoduo-ai-army/luoduo-agent-city

# 3. 把公狼交付的内容包拷入 submissions/luoduo-ai-army/luoduo-agent-city/
#    （覆盖 scaffold 占位，删除 SCAFFOLD-DRAFT 标记）

# 4. 安装依赖 + 生成/校验
python3 -m pip install -r requirements-review.txt
python3 scripts/finalize_submission.py submissions/luoduo-ai-army/luoduo-agent-city
python3 scripts/self_check_submission.py submissions/luoduo-ai-army/luoduo-agent-city --pr-author luoduo-ai-army
python3 scripts/participant_preflight.py submissions/luoduo-ai-army/luoduo-agent-city --pr-author luoduo-ai-army --check-push

# 5. 修复至全 PASS 后提交并开 PR（仅改本目录）
git add submissions/luoduo-ai-army/luoduo-agent-city/
git commit -m "Luoduo AI Army: Agent-City proposal"
git push -u origin submission/luoduo-ai-army/luoduo-agent-city
gh pr create --title "Luoduo Agent-City: AI-Native City with Real Ecosystem Grounding" --body "..." --base main
```

> 严禁改动 `submissions-data.js`（gallery 索引由维护者合并后重生）；PR 文件范围仅限本提案目录。
