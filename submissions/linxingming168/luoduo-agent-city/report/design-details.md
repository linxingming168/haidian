## 一、京张遗址公园公共空间设计（工业遗存 + AI 叙事）

### 1.1 设计母题：人字形铁路 → 智轨之城的叙事骨架
百年京张铁路以「人」字形展线闻名，是中国自主筑路的工业遗产锚点。本设计将这一母题转译为空间语言：

- **线性铁路遗存** → 遗址公园活力带主轴 `jingzhang-spine` 的**空间骨架**（自西直门外大街至北五环的临时范围，沿既有铁路廊道意向）。
- **人字形拓扑** → 东西两翼 `zhongguancun-wing`（中关村科技服务翼）/ `xiaoyuehe-wing`（小月河场景赋能翼）与南北主轴交汇的**缝合节点**；年度「智能体接力跑」活动即沿人字形铁路意向布置，呼应 proposal.md 场景卡⑪。
- **铁锈红（历史锚点）+ 科技蓝（落朵主色）+ 净白底** 的三色风貌体系，呼应 proposal.md 第九章城市风貌设定 `[assumption:A-CULTURE-001]`。

### 1.2 空间组织：一带三段 · 三节点织补
以主轴 `jingzhang-spine` 为脊，串联 3 个重点区（area 要素）与 3 个地标节点（node 要素）：

- **南段（大钟寺—原点社区，约 39.94–39.99）**：商业服务与生活体验，呼应 `dazhongsi-cluster`、`ai-origin-community`；以 `LU-05 商业服务业用地`（1,771,253.54 m²）与 `LU-0804 教育用地` 为基底，叠加 AI+ 生活场景。
- **中段（原点社区—众智园，约 39.99–40.01）**：科研与公共活力，以 `G-06 中段智轨绿带`（379,306.89 m²）、`G-03 中枢智轨绿廊`（227,669.41 m²）为蓝绿缓冲；`open-outcome-gallery`（LM-2）坐落此段。
- **北段（众智园—北五环，约 40.01–40.026）**：自主创新与编排体验，以 `LU-0802 科研用地`（2,088,406.15 m²）、`G-04 众智园科创公园`（426,600.23 m²）为核心；`orchestration-pavilion`（LM-3）、`agent-contribution-wall`（LM-1）坐落此段。

> 工业遗存处理原则（概念）：保留既有铁路线性肌理与枕木/钢轨意象作为铺装与标识，**保留为主、织补连通**；不以拆改结论表达，具体保护范围由文保专项深化 `[boundary_clause.forbidden]`。

### 1.3 AI 交互装置清单（概念 / 试点设想）
沿主轴布置可复制的 AI 交互装置（均设「人工复核开关」与数据最小化，符合 proposal.md 隐私边界 `[agent.3.forbidden]` `[charter.10]`）：

| 装置代号 | 落点 | 交互方式 | 对应 agent |
|---|---|---|---|
| 智轨叙事屏（轨旁数字碑） | 主轴沿线 | 扫码/无感触发铁路历史与城区动态叙事 | 鬼谷子（客服公关）·笔芯秘书 |
| 多语种导视 Agent 柱 | 三节点 + 重点区入口 | 中英等多语种 AR 导览，国际访客友好 | 鬼谷子 |
| 公共信息发布大屏（流媒体） | 广场与节点 | 城区运行态势、活动 IP 发布 | 流媒体/大屏 sy·sj |
| 开源贡献打卡桩 | 荣誉墙 / 展示廊 | GitHub 昵称核验 → 点亮荣誉灯 | 笔芯秘书·论坛 forum_hub |
| 适老化康养陪伴屏 | 原点社区口袋公园 | 健康提示与紧急呼叫（人工复核） | 扁鹊（康养健康官） |
| 城市运行感知底座（EMQX 映射） | 蓝绿网络 | 以真实运行数据采集为公共运行感知的测试验证 | 沈括（数据科学）·松鼠小弟 |

### 1.4 业态建议（10 分钟创新生活圈导向）
- **众智园**：开放研发街区 + 编排中枢体验馆（地标③）+ 开发者共创空间（黑客松，场景卡⑪）。
- **原点社区**：无人零售生活圈（挺盈宝 tyb）、即时服务微节点（易得/落朵售货机 yd）、康养陪伴（适老化）三类可体验 AI+ 生活业态 `[agent.3]`。
- **大钟寺**：智能原生消费与商务场景、永乐大钟文化记忆转译的文创市集与广场活动 `[land_use_plaza_1403_sqm]`。
- **遗址公园沿线**：低干扰的户外展陈、轻餐饮、年度活动 IP 市集，强调公共空间优先。

## 二、东西缝合 / 南北贯通（沿主轴的空间缝合策略）

### 2.1 缝合对象与断点识别（概念）
主轴 `jingzhang-spine` 横亘铁路廊道，历史上形成东西向物理与认知割裂；三重点区沿南北向错落（众智园在北、原点居中、大钟寺在南），需南北向连续慢行。断点类型（概念识别，非工程结论）：

- **东西断点**：铁路廊道两侧步行连通弱、蓝绿不连续。
- **南北断点**：重点区之间慢行路径被道路与用地割裂。

### 2.2 慢行缝合廊道 `slow-traffic-stitch`（概念策略）
聚焦"遗址公园慢行缝合、东西缝合、南北贯通"，**不给出轨道线位 / 道路线形 / 桥隧工程结论** `[boundary_clause.forbidden]` `[assumption:A-TRANSPORT-001]`：

- **南北主轴慢行道**：沿 `jingzhang-spine` 设连续步行/自行车优先带，串联三重点区与三节点；参考 `geometry/roads.geojson` 中 R-001~R-005 五条南北向线性要素（各约 9,438 m）的意向网格，组织"轨道+慢行"复合廊道，强调公共空间优先与青年友好。
- **东西缝合横街**：参考 R-006~R-018 十三条东西向线性要素（各约 1,111 m）的意向网格，在重点区与主轴交点处打通东西向步行横通道，连接 `zhongguancun-wing` 与 `xiaoyuehe-wing` 两翼。
- **平交优先、零新增工程**：以平面步道、过街优先、铺装连续与标识引导实现缝合，回避桥隧/地下工程表述。

### 2.3 蓝绿网络 `blue-green-network` 打通断点
以绿地率与公共空间率为约束构建连续蓝绿基底 `[metric:green_ratio]` `[metric:public_space_ratio]`：

- **绿廊链**：`G-03 中枢智轨绿廊`→`G-06 中段智轨绿带`→`G-04 众智园科创公园`→`G-05 原点社区口袋公园`（398,329.69 m²）形成南北连续绿链；公共空间 `P-01 开源成果展示广场`（606,978.50 m²）作为南段放大节点。
- **合规底线**：绿地与蓝线合规、公共空间优先，不与文保 / 交通安全约束冲突 `[agent.4.forbidden]`。

### 2.4 缝合成效指标（由几何复算，概念）
- 南北慢行贯通长度 ≈ 主轴意向 9.4 km（参考 R-001 类要素）。
- 东西缝合横通道 ≈ 13 条（参考 R-006~R-018），单条约 1.1 km。
- 蓝绿连续网络面积 ≈ 1,431,906 m²（G-03+G-04+G-05+G-06 之和，待复算复核）。

## 三、地标目录：3 个 AI 朝圣地标（对应 spatial.json 三 node 要素）

> 三处地标均为 `geometry/public_space.geojson` 中 `landmark: true` 的概念布点，面积经 EPSG:4548 复算；坐标取自 geojson 实际几何（EPSG:4326 交换值，仅作选址示意）。

### 地标① 智能体贡献荣誉墙 `agent-contribution-wall`（LM-1）
- **定位**：沿遗址公园主线，将入选方案 GitHub 昵称以碑刻/数字屏永久展示，直接呼应征集「刻碑百年」机制 `[charmark]`。
- **几何**：`LM-1`，约 13,651.11 m²，选址示意 116.3474–116.3486 / 40.0174–40.0186（北段·众智园侧）。
- **设计要点**：
  - 铁锈红耐候钢碑刻阵列 + 低能耗数字屏，昵称经开源核验后点亮（呼应场景卡⑩ AI+ 荣誉墙打卡）。
  - 与北侧众智园科创公园 `G-04` 衔接，形成"贡献—创新"叙事闭环。
  - 设人工复核与内容审核开关，仅展示经征集方确认的入选信息。

### 地标② 开源成果展示廊 `open-outcome-gallery`（LM-2）
- **定位**：常设展陈历届提案可视化与可复现成果，形成公共知识沉淀 `[charter.8]`，支持国际传播与年度活动 IP。
- **几何**：`LM-2`，约 13,657.02 m²，选址示意 116.3464–116.3476 / 39.9874–39.9886（中段·原点社区侧）。
- **设计要点**：
  - 半室外展廊 + 可替换数字展面，按届次、按主题（如 jingzhang-heritage-narrative / ai-origin-community）分区。
  - 与 `P-01 开源成果展示广场` 联动，广场作为露天发布与黑客松场地。
  - 知识库与 `笔芯秘书` 知识官联动，成果可溯源至公开仓库与来源登记。

### 地标③ 落朵·智轨调度中枢 `orchestration-pavilion`（LM-3）
- **定位**：以落朵 AI 军团调度理念为原型的体验馆，实时展示城市级 Agent 编排（规划/运营/服务），作为 AI 原生之城的标识性体验节点 `[agent.1]`。
- **几何**：`LM-3`，约 13,652.30 m²，选址示意 116.3464–116.3476 / 40.0114–40.0126（北段·众智园重点区）。
- **设计要点**：
  - 体验馆以"智轨调度台"为视觉核心，可视化 SkyDuo 总控对 24 席 Agent 的任务编排（非实时生产系统，概念演示）。
  - 与 `G-04 众智园科创公园`、科研用地 `LU-0802` 形成"公园—场馆—街区"连续体验动线。
  - 不接入未授权或生产数据，仅以脱敏/合成数据演示 `[agent.3.forbidden]`。

## 四、荣誉展示系统（遗址 / 成就的展示与打卡体系）

### 4.2 打卡体系（city-as-repo 贡献机制）

### 4.3 年度活动 IP（对齐 agent.6）
