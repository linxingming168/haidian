## 二、三期面积与 site 的去重 / 重叠关系

### 2.1 给定口径

- **总体设计范围（site）**：11.4 km² → 几何复算 `site_area_sqm = 11,412,825 m² ≈ 1141.3 万㎡`（`metrics.json`，provisional 边界，待官方红线重算）`[assumption:A-BOUNDARY-001]`。
- **三期概念分期面积（brief 给定，单位 万㎡）**：
  - 第一期 796.7 万㎡
  - 第二期 384.2 万㎡
  - 第三期 728.8 万㎡
  - **三期原始合计 = 1909.7 万㎡**。

### 2.2 去重 / 重叠关系（核心结论）

**1909.7 万㎡ > 1141.3 万㎡（超出 768.4 万㎡），证明三期并非互斥的空间切片，而是存在地理重叠的"分期滚动 / 动态织补"口径。** 关系如下：

- **重叠来源**：同一空间单元可计入多期。典型情形——首期示范段在二、三期持续运营与迭代（荣誉墙、展示廊、体验馆为常设资产，跨期复用）；蓝绿网络、公共连接等基础设施在二期贯通后于三期继续运营。因此多期面积相加会重复计数共享单元。
- **去重后并集约束**：`union(三期) ≤ site = 1141.3 万㎡`。即三期去重并集不可能超过总体设计范围。
- **重叠量下界**：`重叠 ≥ 1909.7 − 1141.3 = 768.4 万㎡`（当 union = site 时取等号）。实际重叠量取决于各期几何定义，须由几何复算确定。
- **运营含义**：分期表达的是"建设与运营推进的时序重点"，而非"把 site 切成三块互不相交的拼图"。这与 proposal.md"保留为主、织补连通"的更新原则一致——分期是节奏，不是切割。

### 2.3 与 geometry/phasing.geojson 的口径差异（须复核）

- 当前 `geometry/phasing.geojson` 仅定义 **PH-1**，`area_sqm_declared = 4,124,934.63 m² ≈ 412.49 万㎡`，与 brief 第一期 796.7 万㎡不一致。
- 差异原因：PH-1 为**几何派生**的单个概念分期多边形；brief 三期 796.7/384.2/728.8 万㎡ 为**规划口径**的分期面积占位值，二者来源与口径不同。
- **处理建议（非结论）**：待补充 PH-2、PH-3 几何后，三期面积应以 `geometry/phasing.geojson` 经 EPSG:4548 复算为准；brief 数值作为 provisional 占位，待几何到位后重算去重并集与重叠量，并更新本清单。正式评分以官方 polygon 为准 `[assumption:A-BOUNDARY-001]` `[source:PROVISIONAL-BOUNDARIES]`。
