# 年度活动机制（赛事 / 论坛 / 开放日 / 黑客松 / 双年展）

> **合规边界（强制）**：本文件所有活动安排均为"概念机制建议 / 可供专业团队与政府深化研究的方案"，不构成已确定的政府安排或已签署的运营承诺 `[agent.6.forbidden]` `[boundary_clause]`。凡涉及政府主办、财政支持、招商政策的表述，均标注为"待官方与运营主体确认"，不写为既成事实。

## 一、机制总览与设计原则

年度活动体系是 agent.6（一带全球 AI 创新活动体系与长期运营）的核心载体，目标是把"城市即开源仓库（city-as-repo）"从静态方案转化为**可持续运营、可招引、可传播**的动态 IP。五类活动构成"金字塔 + 双年锚点"结构：

| 层级 | 活动类型 | 频次 | 角色定位 | 与招商关系 |
|------|----------|------|----------|------------|
| 塔基 | 开放日（Open Day） | 月度 | 公众触达、科普体验 | 品牌认知、居民认同 |
| 塔身 | 黑客松（Hackathon） | 季度 | 开发者共创、场景验证 | 人才与项目招引 |
| 塔身 | 论坛（Forum） | 半年度 | 产业与治理对话 | 企业与资本对接 |
| 塔尖 | 赛事（Challenge） | 年度 | 旗舰 IP、全球声量 | 头部企业落地牵引 |
| 锚点 | 双年展（Biennale） | 双年 | 成果沉淀、国际传播 | 长期品牌资产 |

**五项原则**：① 机制优先于口号（每项均有主办、场地、预算口径、KPI、停止条件）；② 概念活动不得写为已确定安排；③ 招商价值以"可量化触点"表达，不写政策承诺；④ 全部活动呼应征集"刻碑百年"荣誉机制；⑤ 与开发者社区（见 `dev-community.md`）共用贡献—荣誉—转化闭环。

## 二、年度节奏（日历）

```
             Q1         Q2         Q3         Q4

黑客松                  ◉          ◉          ◉        (季度，末月)
论坛             ◉                     ◉              (半年，6月/12月)
赛事                                  ★              (年度旗舰，9–11月)
双年展        ⊞ (偶数年秋季)                              (双年)
```

- **开放日**：全年 12 场，沿遗址公园公共空间与三处重点区轮换，优先使用已有公共空间组件库（`proposal.md` 九节 `component_library`），避免新增工程。
- **黑客松**：每季度 1 场（Q2–Q4 起），"开源黑客松空间"（`scenario_cards` 第 11 项）为常设载体，产出以 PR 进入 city-as-repo 知识库。
- **论坛**：半年 2 场，"中关村科技服务翼"承担要素全球化配置对话，"小月河场景赋能翼"承担场景落地对话。
- **赛事**：年度旗舰，9–11 月，呼应"人字形铁路"智能体接力跑（`scenario_cards` 第 9 项）作为开幕场景。
- **双年展**：偶数年秋季，常设"开源成果展示廊"为内核，叠加轮换展陈，形成可复现成果的公共知识沉淀 `[charter.8]`。

## 三、各类活动机制详述

### 3.1 赛事（Annual AI-City Challenge）★ 年度旗舰
- **定位**：全球 AI 城市创新旗舰 IP，对标征集全球智能体开源精神。
- **形式**：开放命题（空间/运营/场景三类赛道）+ 邀请赛道（落朵 9 大生态真实接口）；终选方案 GitHub 昵称刻入智能体贡献荣誉墙 `[charter.8]`。
- **场地映射**：开幕式于遗址公园主线（接力跑场景），终审与颁奖于落朵·智轨调度中枢体验馆（概念选址）。
- **招商价值**：以"入选即荣誉墙留名 + 方案进入城市知识库"作为企业/团队参与钩子，形成头部企业与人才的自然聚集；不直接承诺落地优惠。

### 3.2 论坛（Luoduo AI Forum）◉ 半年度
- **定位**：产业、资本、治理的对话平台，非招商承诺场。
- **形式**：主旨演讲 + 圆桌 + 生态对接闭门会；议题锚定"AI 原生创新、长期运营价值"等评审维度 `[dimension:long_term_operation_value]`。
- **招商价值**：提供"企业—政府—资本"信息对称触点；所有对接表述为"意向交流"，不写为已确定政策或投资。

### 3.3 开放日（AI Origin Open Day）● 月度
- **定位**：公众与访客的 AI+ 生活体验入口，承载"朝圣与认同" `[scenario_cards 第10项]`。
- **形式**：无人零售生活圈、售货机微节点、康养陪伴、多语种导览等真实生态的体验动线；强调数据最小化与人工复核开关 `[charter.10]`。
- **招商价值**：居民与游客认知沉淀，形成社区级口碑与在地认同，为后续企业落地营造市场环境。

### 3.4 黑客松（City-as-Repo Hackathon）◉ 季度
- **定位**：开发者共创与场景验证主引擎，直连开发者社区转化漏斗（见 `dev-community.md`）。
- **形式**：季度命题（交通慢行 / 公共空间 / 感知底座等），产出以 PR 提交，被采纳即记入荣誉墙与知识库 `[charter.9]`。
- **招商价值**：把参赛者转化为贡献者、再转化为企业/落地（路径见 `dev-community.md` 第三节），是招引的"前端漏斗"。

### 3.5 双年展（Century Jingzhang Biennale）⊞ 双年
- **定位**：长期品牌资产与国际传播锚点，呼应"百年京张"时间尺度。
- **形式**：以"开源成果展示廊"为常设内核 + 双年轮换主题展；展陈可复现成果，支持国际传播与年度活动 IP `[agent.6]`。
- **招商价值**：沉淀可对外传播的城市级 IP，降低后续每届招商的冷启动成本。

## 四、招商价值与品牌 IP 联动

活动体系通过三条链路产生招商价值，且**全部以机制与触点表达，不写为政策承诺**：

1. **声量链路**：赛事 + 双年展 → 全球媒体与开发者关注 → 品牌认知。
2. **人才链路**：黑客松 + 开放日 → 开发者与企业人才库 → 招引前端漏斗。
3. **资本链路**：论坛 + 赛事终审 → 企业—资本—政府信息对称 → 落地对接意向。

品牌 IP 复用：荣誉墙、成果展示廊、调度中枢体验馆作为可复用视觉与空间组件（`component_library`），降低每届运营成本，形成"一次建设、多年复用"的运营经济性。

## 五、运营 KPI 与停止条件（机制保障）

| 活动 | 核心 KPI（概念口径） | 停止 / 退出条件 |
|------|----------------------|------------------|
| 赛事 | 年度参赛方案数、荣誉墙新增刻名数、媒体曝光量 | 连续两年参赛方案 < 阈值 或 无官方/运营主体确认 → 降级为论坛议题 |
| 论坛 | 场次、有效对接意向数（非承诺数） | 连续两届无有效对接记录 → 合并入赛事边会 |
| 开放日 | 参与人次、体验动线复用率 | 单场参与 < 阈值或安全/合规风险 → 暂停并复核 |
| 黑客松 | 有效 PR 数、被采纳方案数 | 连续两季无被采纳 PR → 改为线上轻量赛 |
| 双年展 | 展陈更新率、国际转载量 | 偶数年预算/场地未确认 → 仅保留常设展示廊 |

> 所有 KPI 为概念性运营指标，最终以运营主体核定；停止条件确保活动"可纠偏、不空转"，避免"只写口号无机制" `[agent.6.forbidden]`。
